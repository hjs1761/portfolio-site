## 소개

7년차 PHP 백엔드 개발자입니다. 에이전시에서 4년 10개월간 인증원·병원·법무법인·커머스 등 고객사 사이트를 인수·운영·신규 개발했습니다. 위버로프트에서는 플랫폼 사업 개발팀에서 카페24 기반 D2C 커머스몰의 구축·운영·보안 대응·서비스 종료까지 맡았고, 네오팜·아모레퍼시픽·크래프톤 등 고객사 12곳의 요청을 분석부터 개발, 검증, 근거를 붙인 회신까지 직접 처리해 왔습니다(업무 댓글 659건). 2026년 AI Labs로 팀을 옮겨 지금은 사내 개발 플랫폼(Jira 연동·산출물 관리·RAG 검색)과 AI 도입(AX)을 기획부터 배포, 사내 발표까지 맡고 있습니다.

- **AI 활용(AX)**: 사내 RAG 검색 전 구간 구축(검색 품질 MRR 0.829), Jira 연동 플랫폼, Claude Code 기반 개발과 배포 안전장치
- **커머스 플랫폼**: 카페24 API·웹훅·인앱 전 영역, 멀티샵·스킨 커스텀 기반 D2C 구축·운영 (네오팜 3개 몰 단독 담당, 아모레퍼시픽 4개 몰)
- **백엔드·인프라**: PHP·Laravel·Python, MySQL, AWS·Kubernetes·Docker·GitLab CI/CD 기반 설계·운영
- **CRM·데이터**: 회원 데이터 동기화 설계, 세그먼트 자동 발송, 클릭 추적 → 매출 귀속 대시보드
- **보안·컴플라이언스**: 고객사 보안성검토·ISMS 실사 대응, 개인정보 암호화·파기 증적
- **문제 해결**: 웹훅 유실 데이터 복구, 결제·세션 장애 원인 규명

- **보조**: `Python` `FastAPI` `ASP` `MSSQL` `PostgreSQL(pgvector)` `AWS (EC2·RDS·CloudFront·WAF·Secrets Manager)` `Kubernetes` `Docker` `GitLab CI/CD` `WordPress` `Datadog` `JMeter`
