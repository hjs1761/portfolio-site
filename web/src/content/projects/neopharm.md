## 맡은 일

2023년부터 진행된 카페24 이관과 자체 관리자 시스템 구축 막바지인 2024년 5월에 합류했습니다. QA를 거쳐 7월 말부터 아토팜샵(구 네오팜샵)·리얼베리어몰·티엘스몰 3곳을 개발·운영했습니다.

## 주요 기능

- **자체 관리자 시스템**: 이벤트·프로모션, 통합 배너, 관리자 권한과 로그인 이력, 문자 2차 인증을 구현했습니다.
- **가격 배치**: 상품 최저가 자동 적용(2024.07)과 옵션가 배치(2024.10)를 구현했습니다. 2025년 하반기 카페24 혜택 API의 제약 변경에 맞춰 최저가·앱특가 배치를 다시 작성했습니다.
- **임직원몰 연간 구매한도**: 주문상태 21종을 분류하고 담당자와 합산 대상을 정했습니다. 마이페이지·장바구니·주문서에 같은 계산을 적용해 1인 연 240만 원 초과 결제를 막았습니다(2025년 9월 적용).
- **핀크럭스 CPS 광고 연동**: 매체·고객사와 광고 성과 기준을 정하고, 배송완료 때 구매를 한 번 전송하도록 구현했습니다. 실제 회원 계정으로 전 구간을 확인해 2026년 7월 열었습니다.
- **기획전 기능**: 입장 코드 기반 패밀리세일, 회원등급 확인과 쿠폰 지급을 연동한 VIP 시크릿 특가, 기획전 댓글 연동을 구현했습니다.

## 까다로웠던 점

- **광고 클릭 키 저장 누락**: 리다이렉트를 따라가 매체가 합의한 전용 페이지 대신 특가 상품 페이지로 연결하는 것을 확인했습니다. 공통 레이아웃에서 클릭 키를 저장하도록 바꿔 어느 페이지로 들어와도 남게 했습니다.
- **성과 전송 누락**: 오픈 1주일 뒤 배송완료 알림 대부분이 일괄 처리 경로로 들어오는 것을 확인했습니다. 관리자 구매확정 시 「배송완료」 상태도 1초 만에 지나갔습니다. 두 경로를 전송 대상에 포함하고 주문별 한 번만 정산되도록 했습니다. 누락된 1건은 다시 보냈습니다.
- **옵션가 충돌**: 스팟 이벤트의 옵션가 충돌 원인이 같은 상품의 기획전 두 곳 동시 등록임을 확인했습니다.
