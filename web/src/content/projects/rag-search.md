## 맡은 일

담당자가 바뀌면 찾기 어려워지는 기능 구현 배경을 근거 문서 링크와 함께 답하는 사내 검색을 기획·구현·운영했습니다. 시범 데이터는 네오팜 기록입니다.

## 주요 기능

- **수집과 검색**: 두레이 업무·댓글·메일 수집·정규화부터 청킹·임베딩, 검색·재정렬, 근거 링크를 붙인 답변 생성과 웹 화면까지 구현했습니다. FastAPI와 Docker로 운영합니다.
- **평가셋 게이트**: 실제 질문과 정답 문서를 묶은 평가셋(공개분 62개)으로 변경 사항을 검증합니다. 품질 게이트 4개를 통과해야 반영합니다.
- **LLM 서버 이전**: 인프라 담당과 함께 개인 장비의 모델을 사내 공통 LLM 서버로 옮겼습니다. 모델 후보는 같은 평가셋으로 비교해 정했습니다.
- **기록 범위**: 시범 기간의 질문·답변 추적 기록은 관리자만 조회하게 했습니다. 메신저 원문이 포함된 호출은 기록에서 제외했습니다.

## 까다로웠던 점

- 메일을 한 통 단위로 잘라 색인해 검색 품질(MRR)을 0.722에서 0.829로 높였습니다. 재정렬 후보를 40개에서 100개로 늘린 안은 10문항에서 개선됐지만, 전체 53문항의 정답률이 0.857에서 0.643으로 떨어져 기각했습니다.
- 재정렬 모델이 오류를 삼키고 꺼진 채 동작하는 문제가 세 번 발생했습니다. 대체 동작을 없애고 명시적으로 실패하게 바꿨습니다.
- 같은 질문을 반복한 속도 측정이 캐시 속도를 재고 있어 측정 방법을 바꿨습니다.

## 현재

사내 전체 오픈 전입니다. 수집 자동화와 권한 경계 검증이 남아 있습니다.
