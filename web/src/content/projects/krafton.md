## 맡은 일

국문·영문·중문·일문으로 제공되는 WordPress 기반 크래프톤 공식 홈페이지의 AWS 이관에 참여하고, 이후 운영 개발을 맡았습니다. 이관 환경 검증과 캐시 문제 대응, 채용 API 연동 및 페이지 기능 개발을 수행했습니다.

## 주요 작업

- **이관 준비**: 새 Git 저장소와 GitLab CI 배포 파이프라인을 설정하고, 이관 기간의 접근 제한 처리와 관리자별 API 접근 권한을 정리했습니다.
- **이관 QA**: QA·스테이징 환경을 점검하고 주가 API 검증 스크립트와 콘텐츠 저장 테스트 케이스를 작성했습니다.
- **DB 장애 전환 시험**: 부하 시험 스크립트와 JMeter로 부하를 가한 상태에서 RDS Multi-AZ 장애 전환을 시험하고 Datadog 지표를 확인했습니다.
- **기업 이미지 변경**: 변경된 폰트·로고·이미지·영상 자산을 적용하고 헤더·메인·페이지 스타일을 수정했습니다.
- **채용 페이지 개편**: 그린하우스 API의 공고 조회와 검색을 검증하고, 목록·상세 개편 및 스튜디오별 공고 연동을 반영했습니다.
- **의장 페이지 분리**: 별도 도메인을 유지하며 기존 콘텐츠를 AJAX로 불러오도록 구현했습니다. 자산 경로와 동적 로드 순서를 조정하고 History API로 화면 이동을 처리했습니다.
- **캐시 무효화 절차 정리**: 관리자 화면에서 무효화할 수 있도록 AWS 공식 문서를 검토해 EC2 IAM 역할과 PHP SDK 활용 방법을 정리해 전달했습니다. 이후 구현은 인수자가 진행했습니다.

## 까다로웠던 점

- **일반 사용자의 로그인 화면 이동**: 메인 경로 캐싱 과정에서 관리자 세션 만료 리다이렉트까지 저장된 것이 원인이었습니다. 리다이렉트와 로그인 기록을 추적해 세션 확인 방식을 조정하고, 만료 리다이렉트 차단·쿠키 삭제·관리자 응답 캐시 금지를 적용했습니다.
- **페이지 이동 후 애니메이션 중복**: AJAX로 콘텐츠만 교체하면서 기존 인스턴스·이벤트·타이머가 누적됐습니다. 전환마다 이를 정리하고 링크와 폼 제출도 AJAX 흐름으로 연결했습니다.
- **스튜디오별 채용공고 누락**: 새 공고가 각 스튜디오가 아닌 크래프톤 보드에 등록돼 이름으로 조회되지 않았습니다. 고객사에 등록 상태를 확인받고 연동을 수정했습니다.
