## 맡은 일

2025년 1월 운영 개발로 합류했습니다. 2026년에는 관리자 시스템(서브어드민) 이관, 고객사 보안성 검토·ISMS 대응, 9월 서비스 종료를 맡았습니다. 2026년 Jira 작업 기록은 735.6시간입니다.

## 주요 작업

- **라보에이치 CRM**: 광고성 문자 수신동의 혜택, 회원 데이터 수집·동기화, 세그먼트 자동 발송 6종과 관리자 발송 화면을 개발했습니다. 실발송·중복 차단·클릭 추적과 매출 귀속 대시보드도 구현했습니다.
- **케어박스 추첨제 전환**: 선착순(재고 홀딩) 구조를 없애고 기존 주문 상태와 별도로 추첨 상태 컬럼을 추가했습니다. 데이터 이동 없이 지난 신청과 새 신청을 함께 처리하고, 라보에이치 힐링박스에도 같은 구조를 적용했습니다.
- **관리자 시스템 Kubernetes 환경 구축**: 재이관을 위해 4개 몰의 DB와 소스를 나눴습니다. 스키마 차이 정리, php-fpm·CSP 설정과 배포를 맡았습니다.
- **보안성 검토·ISMS**: 코드의 비밀 값을 AWS Secrets Manager로 옮기고 전 브랜드 프론트 API 쿼리를 prepared statement로 바꿨습니다. SonarQube·모의해킹 지적 사항을 조치하고 라보에이치몰 ISMS 점검 인터뷰·실사에 대응했습니다.
- **서비스 종료**: 메뉴·게시글 자동 숨김, 종료 안내 페이지와 3개 몰의 판매·적립금·쿠폰 사용 종료(9월 1일 0시)를 반영하고 모니터링했습니다. 개인정보 파기 증적 리포트와 라보에이치 뷰티포인트 전환을 처리했습니다.

## 까다로웠던 점

- 외부 API와 내부 관리자 영역 분리 요구가 서버·DB·도메인·프레임워크 전체 변경 논의(약 80\~360인일)로 커지며 이관이 멈췄습니다. 요구사항 원문을 확인해 관리자 화면만 별도 저장소로 분리하는 최소안을 제안했습니다.
- 두 환경에서 「250개 파일이 다르다」는 비교 결과를 다시 확인했습니다. 159개는 줄바꿈·들여쓰기 차이였고, 수정 대상은 약 40개였습니다. 공수 추정은 약 24\~33인일로 줄었습니다.
