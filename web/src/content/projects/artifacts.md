## 맡은 일

HTML 페이지와 이미지 같은 프로젝트별 화면 산출물을 관리하는 사내 구 시스템의 기능을 목록으로 정리하고 재구축했습니다.

## 주요 기능

- **관리 화면 20개**: HTML 에디터, 공통 영역 슬롯, 표 필터, 동시 수정 충돌을 막는 낙관적 잠금.
- **라이브 화면 스냅샷**: 서버가 입력 주소를 열어 촬영하며, 내부망 접근(SSRF)과 DNS 리바인딩 차단.
- **카페24 스킨 미리보기**: 카페24 스킨 지시자가 포함된 페이지 미리보기.
- **배포·운영**: Docker, GitLab CI/CD, 운영 DB 백업 크론, 보안 헤더.

## 까다로웠던 점

- 실사용 첫날 이미지가 깨져 에셋을 내보내는 구조를 재설계했습니다. 기존 주소를 유지하고 에셋 8,955개와 페이지 728개를 누락 없이 옮겼습니다.
- 프로젝트 33개 중 15개는 저장된 이름과 원래 폴더 이름이 달랐습니다. 링크 기록에서 원래 이름을 찾아 맞췄습니다.
