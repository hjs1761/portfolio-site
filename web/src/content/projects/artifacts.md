## 맡은 일

프로젝트별 화면 산출물(HTML 페이지와 이미지 같은 에셋)을 관리하던 사내 구 시스템을 새로 만들었습니다. 구 시스템의 기능을 목록으로 정리한 뒤 설계부터 배포까지 맡았습니다.

## 주요 기능

- **관리 화면 20개** — HTML 에디터와 공통 영역 슬롯, 표 필터, 동시 수정 충돌을 막는 낙관적 잠금.
- **라이브 화면 스냅샷** — 입력한 주소를 서버가 열어 찍는 기능이라, 내부망 접근(SSRF)과 DNS 리바인딩을 막았습니다.
- **카페24 스킨 미리보기** — 카페24 스킨 지시자가 들어 있는 페이지도 미리 볼 수 있게 했습니다.
- **배포·운영** — Docker와 GitLab CI/CD(사내 넥서스 레지스트리), 운영 DB 백업 크론, 보안 헤더.

## 까다로웠던 점

- **실사용 첫날 깨진 이미지** — 에셋을 내보내는 구조를 다시 설계해, 기존 주소는 그대로 두고 에셋 8,955개와 페이지 728개를 누락 없이 옮겼습니다.
- **원래 이름 되살리기** — 프로젝트 33개 중 15개는 저장된 이름이 원래 폴더 이름과 달라, 링크 기록에서 원래 이름을 찾아 맞췄습니다.
